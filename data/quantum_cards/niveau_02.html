8 concepts
ℋ

L'espace de Hilbert

L'espace de Hilbert ℋ = l'espace vectoriel COMPLEXE (avec produit scalaire ⟨·|·⟩) où vivent les états. Un qubit: ℋ = ℂ² (2 amplitudes complexes). n qubits: ℂ^{2ⁿ}. Une particule sur une ligne: dimension infinie. « État quantique » = vecteur unitaire de ℋ.

▾
La formule
$$\mathcal H = \mathbb C^2 \ (\text{qubit}) \qquad \mathcal H_n = (\mathbb C^2)^{\otimes n} = \mathbb C^{2^n}$$
🗣 Comment ça se lit, à voix haute

« l'espace de Hilbert d'un qubit est C deux »; « celui de n qubits est C deux, tenseur n fois, c'est-à-dire C puissance deux puissance n ».

⚛️ En quantique & QC

Toute la question « que peut faire un ordinateur quantique » se formule ici: le vecteur d'état de 50 qubits a 2⁵⁰ composantes — ta RAM de simulateur explose à ~30-45 qubits, et c'est précisément la frontière où le hardware devient intéressant.

🧑‍🏫 Exemple guidé, pas à pas
  1. Compte les nombres réels nécessaires pour décrire n qubits: 2ⁿ amplitudes complexes = 2·2ⁿ réels (moins 2 pour normalisation et phase globale).
  2. n = 10: 2¹⁰ = 1024 amplitudes → trivial. n = 30: ~10⁹ → 16 Go en complex128: ta machine sature déjà.
  3. n = 50: 2⁵⁰ ≈ 10¹⁵ amplitudes → 16 pétaoctets. n = 300: plus d'amplitudes que d'atomes dans l'univers observable.
  4. Résultat: l'espace de Hilbert croît exponentiellement avec le nombre de sous-systèmes — c'est la malédiction du simulateur classique ET la promesse du hardware quantique: la nature « stocke » ce vecteur gratuitement.
🛠 Comment t'en servir

Repère de praticien: simuler en vecteur d'état ≈ jusqu'à 30-35 qubits sur ta machine (RTX incluse), ~45+ sur supercalculateur. Au-delà: tenseurs networks ou vrai hardware.

δᵢⱼ

Bases orthonormées

Une base orthonormée {|i⟩}: des états deux à deux orthogonaux (⟨i|j⟩ = 0 si i≠j) et normalisés (⟨i|i⟩ = 1) — résumé par ⟨i|j⟩ = δᵢⱼ (delta de Kronecker: 1 si i=j, 0 sinon). Orthogonal = parfaitement distinguable par une mesure: la base définit CE QU'ON PEUT demander au système.

▾
La formule
$$\langle i|j\rangle = \delta_{ij} \qquad \sum_i |i\rangle\langle i| = I$$
🗣 Comment ça se lit, à voix haute

« braket i j égale delta i j » — un si les indices sont égaux, zéro sinon. Et la relation de fermeture: « la somme des ket i bra i égale l'identité » — la base couvre tout l'espace.

⚛️ En quantique & QC

La base de calcul {|0⟩, |1⟩} (mesure Z) et la base {|+⟩, |−⟩} (mesure X) sont les deux bases stars du QC. Changer de base de mesure = le cœur de BB84 (crypto quantique) et de la violation de Bell.

🧑‍🏫 Exemple guidé, pas à pas
  1. Vérifie que {|0⟩, |1⟩} est orthonormée: ⟨0|0⟩ = 1, ⟨1|1⟩ = 1, ⟨0|1⟩ = 1·0 + 0·1 = 0 ✓.
  2. Construis la base X: |+⟩ = (|0⟩+|1⟩)/√2, |−⟩ = (|0⟩−|1⟩)/√2. Teste: ⟨+|−⟩ = (1·1 + 1·(−1))/2 = 0 ✓ orthogonaux.
  3. Point crucial: |+⟩ n'est PAS orthogonal à |0⟩: ⟨0|+⟩ = 1/√2 → une mesure Z sur |+⟩ donne 0 ou 1 à 50/50. Deux états non orthogonaux sont IMPOSSIBLES à distinguer de façon fiable — le fondement de la crypto quantique.
  4. Résultat: « orthogonal » = « distinguable en une mesure », « non orthogonal » = « confusion inévitable ». Cette équivalence géométrie ↔ information est le théorème le plus utile du domaine.
🛠 Comment t'en servir

En circuit: mesurer dans la base X = appliquer H puis mesurer en Z. Toute « mesure dans une autre base » se ramène à: rotation unitaire + mesure standard.

Σcᵢ|i⟩

Décomposer un état sur une base

Tout état s'écrit |ψ⟩ = Σᵢ cᵢ|i⟩ avec cᵢ = ⟨i|ψ⟩: les coefficients s'obtiennent par projection (braket). Les |cᵢ|² sont les probabilités de mesure dans cette base, et Σ|cᵢ|² = 1. Changer de base = réécrire le MÊME état avec d'autres coefficients.

▾
La formule
$$|\psi\rangle = \sum_i c_i\,|i\rangle, \quad c_i = \langle i|\psi\rangle, \quad \sum_i |c_i|^2 = 1$$
🗣 Comment ça se lit, à voix haute

« ket psi égale la somme des c i, ket i — où c i égale braket i psi ». Les coefficients sont les « ombres » de l'état sur chaque vecteur de base.

⚛️ En quantique & QC

C'est le geste permanent: exprimer l'état dans la base de la mesure pour lire les probabilités. Un algorithme quantique = préparer des cᵢ dont les modules concentrent la probabilité sur les bonnes réponses.

🧑‍🏫 Exemple guidé, pas à pas
  1. Prends |ψ⟩ = |0⟩ et décompose-le dans la base X {|+⟩, |−⟩}.
  2. c₊ = ⟨+|0⟩ = (⟨0|+⟨1|)/√2 · |0⟩ = 1/√2. c₋ = ⟨−|0⟩ = 1/√2.
  3. Écris: |0⟩ = (|+⟩ + |−⟩)/√2 — l'état « certain » en base Z est une superposition 50/50 en base X !
  4. Vérifie: |1/√2|² + |1/√2|² = 1 ✓. Mesure en Z: résultat 0 certain. Mesure en X: pile ou face. MÊME état, questions différentes, certitudes différentes.
  5. Résultat: la superposition n'est pas une propriété absolue d'un état mais RELATIVE à une base. « Être en superposition » signifie toujours « ...dans telle base ». Cette nuance désamorce la moitié des paradoxes de vulgarisation.
🛠 Comment t'en servir

En code, les coefficients d'un vecteur d'état dans une autre base: c = B.conj().T @ psi où les colonnes de B sont la nouvelle base. Une multiplication matricielle, pas un mystère.

XYZ

Les matrices de Pauli

X, Y, Z: trois matrices 2×2 qui sont à la fois les rotations fondamentales du qubit et les observables de spin. X = bit-flip (échange |0⟩↔|1⟩), Z = phase-flip (signe de |1⟩), Y = les deux. Avec I, elles forment une base de TOUTES les matrices 2×2: le quantique d'un qubit tient dans quatre matrices.

▾
La formule
$$X=\begin{pmatrix}0&1\\1&0\end{pmatrix} \quad Y=\begin{pmatrix}0&-i\\i&0\end{pmatrix} \quad Z=\begin{pmatrix}1&0\\0&-1\end{pmatrix}$$
🗣 Comment ça se lit, à voix haute

« X, Y, Z: les matrices de Pauli ». Propriétés qui se récitent: « X carré égale Y carré égale Z carré égale l'identité », et « X Y égale i Z » (et cycliquement).

⚛️ En quantique & QC

Les portes X/Y/Z des circuits; les axes de la sphère de Bloch; les termes des hamiltoniens (H = ΣJᵢⱼZᵢZⱼ + ...); les erreurs élémentaires que corrigent les codes (toute erreur 1-qubit = combinaison de X, Y, Z). Omniprésentes.

🧑‍🏫 Exemple guidé, pas à pas
  1. Applique X à |0⟩: [[0,1],[1,0]]·(1,0) = (0,1) = |1⟩ → X est le NOT quantique ✓.
  2. Applique Z à |+⟩ = (1,1)/√2: Z|+⟩ = (1,−1)/√2 = |−⟩ → Z ne change pas les probas en base Z (|amplitudes| intactes) mais retourne la PHASE relative — invisible en Z, décisif en X.
  3. Vérifie l'anticommutation: XZ = [[0,−1],[1,0]] et ZX = [[0,1],[−1,0]] → XZ = −ZX. Elles ne commutent pas: ordre des portes ≠ interchangeable.
  4. Calcule les états propres: X a pour états propres |+⟩ (valeur +1) et |−⟩ (−1); Z a |0⟩ et |1⟩. « Mesurer X » et « mesurer Z » = questions incompatibles (carte 29).
  5. Résultat: apprends ces trois matrices PAR CŒUR — c'est l'alphabet. Tout le niveau 6 (portes) et le niveau 8 (erreurs) les recycle sans répit.
🛠 Comment t'en servir

Mnémotechnique Bloch: X, Y, Z = rotations de 180° autour des axes x, y, z de la sphère. Une erreur matérielle quelconque sur un qubit se décompose toujours en « un peu de X, un peu de Y, un peu de Z ».

A=A†

Hermitien = observable

Une matrice hermitienne (A = A†) a deux super-pouvoirs garantis: valeurs propres RÉELLES (des résultats de mesure sensés) et états propres ORTHOGONAUX (des résultats distinguables). C'est pourquoi le postulat dit: toute grandeur mesurable EST un opérateur hermitien.

▾
La formule
$$A = A^\dagger \ \Rightarrow\ a_i \in \mathbb R,\ \ \langle a_i|a_j\rangle = \delta_{ij}$$
🗣 Comment ça se lit, à voix haute

« si A égale A dague, alors ses valeurs propres a i sont réelles et ses vecteurs propres sont orthogonaux » — hermitien implique mesurable proprement.

⚛️ En quantique & QC

Le hamiltonien (énergie), les Pauli (spin), la position, l'impulsion: tous hermitiens. En QC, « mesurer l'observable Z₁Z₂ » (parité de deux qubits) est le geste de base de la correction d'erreur.

🧑‍🏫 Exemple guidé, pas à pas
  1. Prends A = [[2, 1−i], [1+i, 3]]. Vérifie l'hermiticité: transpose → [[2, 1+i], [1−i, 3]], conjugue → [[2, 1−i], [1+i, 3]] = A ✓. Note la structure: diagonale RÉELLE, hors-diagonale en paires conjuguées.
  2. Calcule ses valeurs propres (trace = 5, det = 6 − |1−i|² = 6−2 = 4): λ² − 5λ + 4 = 0 → λ = 1 et λ = 4. RÉELLES ✓, comme promis.
  3. Interprète: une mesure de « l'observable A » ne peut donner QUE 1 ou 4 — jamais 2.5, jamais un complexe. Le spectre EST le menu des résultats possibles.
  4. Résultat: la valeur moyenne ⟨A⟩ = ⟨ψ|A|ψ⟩ (carte 22) sera une moyenne pondérée de ces valeurs propres. Hermitien = le tampon « cette matrice a le droit d'être une question posée à la nature ».
🛠 Comment t'en servir

En code: np.linalg.eigh (le h!) exploite l'hermiticité: plus rapide, valeurs propres réelles triées. Si eig te sort des valeurs propres complexes pour un « observable », ta matrice n'est pas hermitienne — bug.

U†U=I

Unitaire = évolution

Une matrice unitaire (U†U = I) préserve les normes et les brakets: les probabilités totales restent 1, l'information n'est ni créée ni détruite. TOUTE évolution quantique fermée (portes, Schrödinger) est unitaire — et donc RÉVERSIBLE: U⁻¹ = U†, il suffit de « conjuguer le circuit ».

▾
La formule
$$U^\dagger U = I \qquad \|U|\psi\rangle\| = \||\psi\rangle\| \qquad U^{-1}=U^\dagger$$
🗣 Comment ça se lit, à voix haute

« U dague U égale l'identité »; conséquence: « la norme de U psi égale la norme de psi » et « l'inverse de U est U dague » — l'évolution quantique se rembobine en prenant l'adjoint.

⚛️ En quantique & QC

Chaque porte d'un circuit est une unitaire; le circuit entier est LEUR PRODUIT (une grosse unitaire). L'« uncompute » (défaire des calculs intermédiaires en appliquant U†) est une technique standard des algorithmes. La non-unitarité n'entre que par la mesure et le bruit.

🧑‍🏫 Exemple guidé, pas à pas
  1. Vérifie que H (Hadamard) = (1/√2)[[1,1],[1,−1]] est unitaire: H† = H (elle est aussi hermitienne), et H·H = (1/2)[[2,0],[0,2]] = I ✓. Bonus: H est son propre inverse — l'appliquer deux fois revient au départ.
  2. Teste la conservation: |ψ⟩ = (0.6, 0.8), norme 1. H|ψ⟩ = ((0.6+0.8)/√2, (0.6−0.8)/√2) = (0.99, −0.141). Norme² = 0.98 + 0.02 = 1 ✓ — pas une goutte de probabilité perdue.
  3. Contre-exemple: M = [[1,0],[0,0.5]] « atténue » |1⟩: M|+⟩ a une norme < 1 → M détruit de l'information: interdite comme porte (mais utile pour modéliser des PERTES, niveau 8).
  4. Résultat: unitaire = « rotation généralisée » de l'espace de Hilbert. Un circuit quantique ne fait que TOURNER un grand vecteur — la mesure finale décide où le couperet tombe.
🛠 Comment t'en servir

Réflexe Qiskit: circuit.inverse() existe précisément parce que tout est unitaire. Et pour tester une matrice maison: np.allclose(U @ U.conj().T, np.eye(n)) — une ligne, zéro excuse.

|a⟩⟨a|

Les projecteurs

P = |a⟩⟨a| (« ket-bra ») = le projecteur sur l'état |a⟩: appliqué à |ψ⟩, il en extrait la composante le long de |a⟩. Signature: P² = P (projeter deux fois = projeter une fois) et P† = P. C'est l'outil mathématique de la MESURE.

▾
La formule
$$P_a = |a\rangle\langle a| \qquad P_a^2 = P_a \qquad P_a|\psi\rangle = \langle a|\psi\rangle\,|a\rangle$$
🗣 Comment ça se lit, à voix haute

« P a égale ket a, bra a ». Appliqué à psi: « P a psi égale braket a psi, fois ket a » — le nombre ⟨a|ψ⟩ (l'amplitude) devant l'état |a⟩.

⚛️ En quantique & QC

La mesure projective: résultat a avec proba ⟨ψ|Pₐ|ψ⟩ = |⟨a|ψ⟩|², état après mesure = Pₐ|ψ⟩ renormalisé. Les observables se décomposent en projecteurs: Z = (+1)|0⟩⟨0| + (−1)|1⟩⟨1| — la décomposition spectrale.

🧑‍🏫 Exemple guidé, pas à pas
  1. Construis P₀ = |0⟩⟨0| = colonne(1,0) × ligne(1,0) = [[1,0],[0,0]].
  2. Applique-le à |ψ⟩ = (0.6, 0.8): P₀|ψ⟩ = (0.6, 0) — la composante |1⟩ a été rasée, seule l'ombre sur |0⟩ survit.
  3. Vérifie P₀² = P₀: [[1,0],[0,0]]² = [[1,0],[0,0]] ✓. Une fois projeté, reprojeter ne change rien — voilà pourquoi répéter la même mesure redonne le même résultat.
  4. Utilise-le pour la mesure: proba(0) = ⟨ψ|P₀|ψ⟩ = 0.36; état après: (0.6,0)/0.6 = (1,0) = |0⟩. Tu viens de dérouler le postulat de la mesure entièrement en algèbre.
  5. Résultat: le « collapse » mystique = une projection + une renormalisation. Deux opérations de lycée. Le ket-bra |a⟩⟨a| est aussi la brique des matrices densité (niveau 5) — investis-le maintenant.
🛠 Comment t'en servir

Astuce de lecture des papiers: toute expression de la forme Σᵢ λᵢ|i⟩⟨i| est une décomposition spectrale — « l'opérateur, raconté par ses résultats de mesure possibles ». Repère-la, elle est partout.

⟨A⟩

Valeur moyenne et trace

⟨A⟩ = ⟨ψ|A|ψ⟩: la MOYENNE des résultats de mesure de A sur l'état |ψ⟩ (moyenne d'ensemble: mille copies, mille mesures, moyenne). Version générale avec la trace: ⟨A⟩ = Tr(ρA). C'est LE nombre que calculent VQE et toute la chimie quantique.

▾
La formule
$$\langle A\rangle = \langle\psi|A|\psi\rangle = \sum_i a_i\,|\langle a_i|\psi\rangle|^2$$
🗣 Comment ça se lit, à voix haute

« la valeur moyenne de A égale bra psi, A, ket psi » — un sandwich: l'opérateur entre le bra et le ket. Égal aussi à « la somme des valeurs propres a i, pondérées par leurs probabilités ».

⚛️ En quantique & QC

L'énergie moyenne ⟨H⟩ est la quantité que VQE minimise (niveau 9). En labo, chaque « expectation value » publiée = ce sandwich, estimé en répétant le circuit des milliers de fois (les « shots »).

🧑‍🏫 Exemple guidé, pas à pas
  1. Prends |ψ⟩ = (0.6, 0.8) et l'observable Z.
  2. Méthode sandwich: Z|ψ⟩ = (0.6, −0.8), puis ⟨ψ|·(0.6, −0.8) = 0.6×0.6 + 0.8×(−0.8) = 0.36 − 0.64 = −0.28.
  3. Méthode probabiliste (contrôle): P(+1) = 0.36, P(−1) = 0.64 → moyenne = (+1)(0.36) + (−1)(0.64) = −0.28 ✓ — les deux routes coïncident, comme il se doit.
  4. Interprète: chaque mesure individuelle donne +1 OU −1 (jamais −0.28); c'est la MOYENNE sur les répétitions qui vaut −0.28. Avec 1000 shots, tu l'estimes à ±0.03 près (bruit statistique en 1/√N).
  5. Résultat: le sandwich ⟨ψ|A|ψ⟩ est à la fois trois lignes de NumPy et des heures de temps machine réel — comprendre ce double statut (nombre exact / estimation par shots) est ce qui distingue le praticien du théoricien.
🛠 Comment t'en servir

En code: psi.conj() @ A @ psi. En hardware: choisis ton nombre de shots selon la précision voulue (erreur ∝ 1/√shots) — le budget de mesure est un vrai coût, compte-le.
